# inventory-management-system

Este proyecto es un sistema de gestión de inventario diseñado para administrar productos, controlar entradas y salidas, generar reportes y visualizar el estado del inventario en tiempo real.
Incluye herramientas completas para la administración de productos y el seguimiento de ventas, ofreciendo una solución robusta para negocios, almacenes y tiendas.

Características principales
Gestión completa de productos

Crear producto

Editar producto

Eliminar producto

Actualizar propiedades (precio, cantidad, categoría, etc.)

Inventario en tiempo real

Visualización instantánea del stock

Filtros por categoría, precio, cantidad, estado, etc.

Control de movimientos

Registro de ventas

Registro de entradas de mercancía

Historial de movimientos

Reportes en PDF

Generación de reportes del inventario

Reportes de ventas

Reportes de productos agotados o con bajo stock

Interfaz intuitiva

Navegación clara

Panel de control
